# Security Policy

## Supported versions

The latest tagged release receives security fixes. Older pre-release versions
may be fixed at the maintainers' discretion.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue with exploit details, credentials, private data, or a proof of concept that could put users at risk.

Include:

- the affected file, package, or version
- the impact and conditions required to reproduce it
- a minimal reproduction when safe to share
- any suggested mitigation

The maintainers will review the report, coordinate validation, and discuss disclosure timing with the reporter. A report may be closed if it does not affect code maintained by this project.

## Scope

This policy covers only code published in this repository. Reports about
unrelated products, hosted services, or third-party dependencies should be sent
to the responsible project or vendor.
